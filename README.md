# سید — ربات تلگرام روی Cloudflare Workers

یک Worker **ماژولار**، بدون سرور، بدون حافظه‌ی گفتگو. دو provider: **Gemini بومی** (متن، عکس، ویدیو، صدا) و **هر سرویس OpenAI-سازگار** (OpenRouter، justwoker و…).

> **از کجا شروع کنم؟** → [`DEPLOY-MODULES.md`](DEPLOY-MODULES.md) · نصب ۱۶ ماژول در تب Modules داشبورد
> `DEPLOY-DASHBOARD.md` راهنمای نسخه‌ی تک‌فایلی است.

| مسیر | کارش |
|---|---|
| `POST /` | وب‌هوک تلگرام |
| `GET /admin` | پنل مدیریت: تنظیمات، رسانه و ایمنی، آرشیو |
| `GET /admin/api/log` | آرشیو ۲۰۰ پیام اخیر (فقط مدیر) |
| `GET /setup` | ست کردن خودکار وب‌هوک تلگرام |
| `GET /diag` | تست زنده: تلگرام، وب‌هوک، کلیدها و یک پاسخ واقعی از مدل |

## ماژول‌ها

```
index.js            مسیریابی و تأیید وب‌هوک
text.js             مارک‌داون، تکه‌بندی، نرمال‌سازی فارسی، base64
store.js            KV: تنظیمات، مهاجرت، آمار
http.js             خطای API با وضعیت و POST مشترک
trigger.js          تصمیم جواب دادن + دستورها
prompt.js           سه شخصیت و ساخت پرامپت خنثی
telegram.js         کلاینت Bot API و ارسال جواب
archive.js          آرشیو ۲۰۰ پیام
media.js            عکس/ویدیو/صدا → base64 خنثی
providerOpenai.js   ترجمه‌ی محتوا به فرمت OpenAI
providerGemini.js   ترجمه‌ی محتوا به فرمت Gemini + ایمنی
llm.js              دیسپچر بین دو provider
answer.js           خط لوله‌ی جواب، صف هر چت، سقف روزانه
admin.js            مسیرها و HTML پنل
tools.js            /diag و /setup
```

بین ماژول‌ها یک **فرمت محتوای خنثی** رد و بدل می‌شود:

```js
{ type: "text",  text }
{ type: "image", mime, data }   // base64
{ type: "video", mime, data }
{ type: "audio", mime, data }
```

هر provider خودش ترجمه‌اش می‌کند، پس بقیه‌ی برنامه اصلاً نمی‌داند با چه سرویسی حرف می‌زند. تعویض provider یک `Save` در پنل است، نه یک Deploy.

## استقرار، گام به گام

> اگر ترمینال نمی‌خواهی، `DEPLOY-MODULES.md` را دنبال کن (کاملاً با مرورگر). بخش زیر برای استقرار با CLI است.

### ۱) ابزارها
Node.js 20+ نصب باشد. بعد در همین پوشه:

```powershell
npm install
npx wrangler login
```

### ۲) فضای ذخیره‌سازی بساز (KV)
```powershell
npx wrangler kv namespace create CONFIG
```
یک `id` چاپ می‌شود. در فایل `wrangler.toml` جای `REPLACE_WITH_YOUR_KV_NAMESPACE_ID` را با آن عوض کن.

### ۳) Secretها را ست کن
```powershell
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put ADMIN_PASSWORD
```
اولی توکن BotFather، دومی کلید از [aistudio.google.com/apikey](https://aistudio.google.com/apikey)، سومی رمز پنل `/admin`.

اختیاری: `npx wrangler secret put API_KEY` برای یک سرویس OpenAI-سازگار جایگزین.

> (اگر ویندوز ایراد اسکریپت داد: `npx.cmd wrangler secret put ...`)

### ۴) دیپلوی
```powershell
npx wrangler deploy
```
یک آدرس می‌دهد مثل `https://sayyad-bot.workers.dev`

### ۵) وب‌هوک تلگرام را ست کن
این آدرس را باز کن:
```
https://sayyad-bot.workers.dev/setup
```
باید `"ok": true` ببینی. (پیام‌هایی که قبل از این لحظه در صف تلگرام بوده‌اند دور ریخته می‌شوند؛ برای ریست از `/setup/reset` استفاده کن.)

### ۶) تست
```
https://sayyad-bot.workers.dev/diag
```
اگر `checks.text.ok` و `checks.image.ok` هر دو `true` باشد، همه‌چیز سالم است.
(هر بار که `/diag` را باز می‌کنی، دو درخواست به OpenRouter مصرف می‌شود؛ حواست به سقف روزانه باشد.)

### ۷) پنل مدیریت
```
https://sayyad-bot.workers.dev/admin
```
رمز `ADMIN_PASSWORD` را بزن. از اینجا حالت (ادب / دانای کل / بددهن)، متن شخصیت، سقف توکن، سقف حجم ویدیو، **سقف درخواست روزانه** و کلید روشن/خاموش را تنظیم می‌کنی. ذخیره = یک کلیک روی Save.

> **سقف روزانه (Daily request cap)** را روی ۵۰ نگه دار. ربات قبل از هر تماس با مدل چک می‌کند که امروز چند درخواست رفته؛ اگر به سقف رسیده باشد اصلاً به OpenRouter زنگ نمی‌زند و یک پیام «امروز از سقف روزانه‌ام رد شدیم» می‌دهد (برای هر چت، هر یک ساعت یک‌بار). اگر اعتبار خریدی و سقف بالاتر رفت، از همین پنل زیادش کن. با ۰ کاملاً غیرفعال می‌شود.

### ۸) اضافه کردن به گروه — مهم‌ترین مرحله
ربات را به گروه اضافه کن و **یکی از این دو کار** را انجام بده، وگرنه پیام‌های گروه را نمی‌بیند:

- **الف)** در BotFather: `/setprivacy` → ربات سید → `Disable`
- **ب)** ربات را **ادمین** گروه کن

بعد ربات را در گروه تست کن: بنویس `سید این چیه؟`

## رفتار ربات

**در گروه**
- هر پیامی که کلمه‌ی «سید» داخلش باشد → جواب می‌دهد (با «ي/ك» عربی، اعراب و کشیده هم می‌شناسد).
- ریپلای روی پیام خودِ سید (بدون کلمه‌ی «سید») → جواب می‌دهد.
- ریپلای روی پیام بقیه بدون «سید» → ساکت می‌ماند.
- پیام بوت‌های دیگر → نادیده.

**در چت خصوصی** → به هر پیامی جواب می‌دهد.

**ریپلای** → هر دو طرف فرستاده می‌شود: متن پیامی که ریپلای شده + سوال شما. جواب هم **ریپلای روی پیام خودت** ارسال می‌شود.

**رسانه** → عکس، ویدیو، ویدیوی بدون صدا و گیف تا سقف حجم تنظیم‌شده (پیش‌فرض ۴ مگابایت) واقعاً به مدل فرستاده می‌شود. بزرگ‌تر از آن یا فایل صوتی → به‌جای فایل، یک توضیح متنی برای مدل فرستاده می‌شود.

**ویس نوت** → جواب **صوتی** می‌آید: متن جواب از مسیر Live API (`gemini-3.8-live`) با صدای فارسی خوانده می‌شود و به‌صورت فایل صوتی (WAV) ریپلای روی پیامت ارسال می‌شود — متن همراهش نیست. نیازمند `GEMINI_API_KEY`. اگر ساخت صدا شکست خورد، یک پیام خطای خودمانی می‌رسد، نه سکوت. متن‌های بلندتر از حدود ۱۵۰۰ کاراکتر کوتاه می‌شوند تا از سقف زمانی ۳۰ ثانیه‌ای Worker رد نشویم.

**حافظه** → هیچ. هر پیام کاملاً مستقل است.

**همزمانی** → در هر گروه فقط یک درخواست همزمان؛ پیام‌های بعدی صف می‌شوند.

**فرمت** → مارک‌داون به HTML تبدیل و ارسال می‌شود؛ اگر تلگرام گیر داد، خودکار بدون فرمت می‌فرستد. جواب‌های بلند خودکار چندپیامی می‌شوند.

**دستورها** → `/start` `/help` `/ping`

**آرشیو مدیر** → هر پیامی که تلگرام به ربات تحویل می‌دهد (چه جواب بگیرد چه نگیرد) در KV نگه داشته می‌شود؛ ۲۰۰ تای آخر، جدیدترین اول. در تب **Message log** پنل دیده می‌شود: نام و شماره فرستنده، نام و شماره گروه، ساعت دقیق، و متن کامل بدون کوتاه‌سازی. مدیا ذخیره نمی‌شود، فقط یادداشت می‌شود که «داشته یا نداشته». **این آرشیو هرگز به مدل فرستاده نمی‌شود** — حافظه‌ی گفتگو همچنان صفر است.

## چالش‌ها و مرزها

| موضوع | وضعیت |
|---|---|
| **سقف پلن رایگان Gemini** | سقف‌ها **بر اساس پروژه** اعمال می‌شوند نه بر اساس کلید، و عدد دقیقشان در AI Studio است نه در مستندات. برای همین «سقف روزانه» در پنل هست: ربات قبل از تمام شدن سهمیه خودش متوقف می‌شود و پیام روشن می‌دهد. |
| **سقف پلن رایگان OpenRouter** | مدل‌های `:free` روی ۲۰ درخواست در دقیقه و ۵۰ در روز (اگر تا حالا ۱۰ اعتبار نخریده باشی) و ۱۰۰۰ در روز بعد از خرید. |
| **ممکن است Worker بلاک شود** | هر دو provider پشت Cloudflare هستند و قبلاً دیده‌ایم که درخواستِ Worker را با ۴۰۳ رد می‌کنند، در حالی که `curl` از کامپیوتر کار می‌کند. اگر `/diag` خطای ۴۰۳ داد، هدر `User-Agent` معمولاً حلش می‌کند. |
| **فیلتر ایمنی Gemini** | گوگل روی پلن رایگان معمولاً `BLOCK_NONE` را برای harassment و hate speech رد می‌کند و بی‌صدا به سطح سخت‌گیرانه‌تر برمی‌گردد. پس با پرسونالیت تند، انسیدر محتمل است. |
| **CPU پلن رایگان** | کلودفلر به هر درخواست ۱۰ms CPU می‌دهد و base64 کردن ویدیو از این رد می‌شود (انتظار I/O مصرف نمی‌شود، ولی محاسبه مصرف می‌شود). سقف ویدیو را روی ۴MB نگه دار. برای بزرگ‌تر، پلن Workers Paid (۵ دلار/ماه، ۳۰s CPU). |
| **حریم خصوصی تلگرام** | تا وقتی `/setprivacy` را `Disable` نکنی یا ربات ادمین نباشد، پیام‌های گروه را نمی‌گیرد. |
| **حافظه** | عمداً ندارد. برای «بیشتر توضیح بده» باید ریپلای کنی (که خودکار جواب قبلی را می‌فرستد). |
| **سقف KV رایگان** | ۱۰۰۰ نوشتن در روز. هر پیام دو نوشتن می‌گیرد (آمار + آرشیو). اگر پر شد خطا بی‌صدا رد می‌شود: ربات و پنل سالم می‌مانند و فقط آرشیو پر نمی‌شود. |
| **دانلود فایل تلگرام** | `getFile` فقط برای فایل‌های زیر ۲۰MB کار می‌کند. |
| **ویدیو و صدا** | فقط از مسیر **Gemini بومی** پشتیبانی می‌شوند. با provider سازگار، `video_url` و `input_audio` به توضیح متنی تبدیل می‌شوند تا جواب بقیه‌ی پیام سالم بماند. Gemini از inline زیر ۱۰۰MB قبول می‌کند؛ سقف واقعی نزد ما همان سقف CPU است. |
| **جواب صوتی (Live API)** | خروجی صدا از WebSocket زنده می‌آید و باید در همان پنجره‌ی ۳۰ ثانیه‌ای `waitUntil` تمام شود؛ به همین دلیل متن بلند کوتاه می‌شود و اگر صدا دیر بیاید، همان تکه‌ای که رسیده ارسال می‌شود. `turnComplete` سرور گاهی تا ۳۰ ثانیه طول می‌کشد، پس روی بی‌حرکتی ۲.۵ ثانیه‌ای هم بسته می‌شود. |
| **۴۰۹۶ کاراکتر تلگرام** | حد بعد از parse شدن entityهاست. کد جواب‌ها را بر اساس اندازه‌ی HTML رندرشده تکه‌تکه می‌کند، نه متن خام. |
| **مارک‌داون مدل** | هر `<` و `&` قبل از ارسال escape می‌شود و اگر تلگرام باز هم ۴۰۰ داد، همان پیام بدون فرمت دوباره فرستاده می‌شود. |
| **پیام تکراری** | با `update_id` و `secret_token` مهار شده. |
| **تعویض provider** | از پنل `/admin`: تب Settings → Provider. یک `Save`، بدون Deploy. اگر کلید provider انتخابی نبود، کد به provider دیگر می‌افتد — ولی فقط برای خطای «کلید نداری»؛ خطای ۴۲۹ یا پرامپت بد به کاربر گزارش می‌شود. |
| **پروسایدرهای مختلف** | یک مدل ممکن است پشتش چند پروسایدر باشد و یکی `reasoning` را قبول نکند یا `max_tokens` را رد کند. مسیر OpenAI-سازگار سه بار تلاش می‌کند: با reasoning، بدون reasoning، و با `max_completion_tokens`. فقط خطای ۴۰۰/۴۲۲ این مسیر را فعال می‌کند؛ ۴۲۹ هرگز تکرار نمی‌شود. |
| **مهاجرت تنظیمات** | نسخه‌ی قبل کلیدهای `config:v1` و `stats:v1` را در KV می‌نوشت. نسخه‌ی جدید بار اول آن‌ها را به `config:v2` / `stats:v2` منتقل می‌کند و پرسونالیت‌ها و حالت انتخابی حفظ می‌شوند. |

## استخر مدل

Gemini سهمیه‌ی **جدا برای هر مدل** دارد. ربات یک فهرست مدل دارد و قوی‌ترین را اول صدا می‌زند؛ اگر سهمیه‌ی روزانه‌ی آن تمام شده باشد، مدل بعدی را امتحان می‌کند و مدل تمام‌شده را تا نیمه‌شب به وقت پسیم کنار می‌گذارد.

```js
gemini-3.8-flash      ← اول
gemini-3.7-flash
...
gemini-3.5-flash-lite ← ۵۰۰ در روز
Antigravity           ← آخرین شانس
```

فهرست از پنل `/admin` قابل ویرایش است. مجموع ظرفیت روزانه حدود **۱۱۲۰ درخواست** می‌شود، به‌جای ۲۰.

| رفتار | نتیجه |
|---|---|
| خطای «سقف **دقیقه**» | با مکث کوتاه دوباره امتحان می‌شود |
| خطای «سقف **روز**» | بلافاصله مدل بعدی، بدون اتلاف درخواست |
| نام مدل اشتباه (۴۰۴) | یک درخواست هدر می‌رود و مدل تا فردا کنار گذاشته می‌شود |
| تمام شدن همه‌ی مدل‌ها | پیام با **ساعت دقیق ریست** به وقت تهران |
| خطای واقعی (۵۰۰، پرامپت بد) | اصلاً مدل عوض نمی‌کند — کاربر می‌فهمد چه شده |

قفل هر مدل خودش را پاک می‌کند، پس هیچ کار پس‌زمینه‌ای لازم نیست.

## توسعه

```powershell
npm test          # build + بیش از ۱۷۰ تست آفلاین در ۱۳ مجموعه، بدون شبکه
npm run build     # ساخت dist/sayyad-worker.js از روی گراف import
npx wrangler dev  # اجرای محلی (اول .dev.vars را از .dev.vars.example بساز)
```

هر مجموعه‌ی تست یک لایه را می‌سنجد و همه از روی **`dist/sayyad-worker.js`** import می‌شوند — یعنی همان فایلی که واقعاً منتشر می‌شود، نه یک کپی موازی از منطق.

```
build.mjs          باندلر: گراف import را می‌خواند، ترتیب توپولوژیک می‌دهد
src/*.js           ۱۶ ماژول، با نام‌های بدون پسوند
test/harness.mjs   مشترک: باندل، KV ساختگی، env
test/test-*.mjs    یک فایل برای هر لایه
dist/              خروجی تک‌فایلی (اختیاری، برای استقرار بدون تب Modules)
```

> کلید توکن ربات و کلید Gemini در این گفتگو فرستاده شده‌اند؛ اگر جایی عمومی شده‌اند، از BotFather و Google AI Studio قابل عوض کردن‌اند.
